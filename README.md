# AI Resume Analyzer

This project analyzes how well a resume matches a job description using NLP techniques.

## Features
- Upload resume (PDF)
- Paste job description
- Get match score
- Simple and interactive UI

## Tech Stack
- Python
- Streamlit
- Scikit-learn (TF-IDF, Cosine Similarity)

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run app:
   streamlit run app.py
